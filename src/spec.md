# Specification

## Summary
**Goal:** Add a submit button to the booking form to allow users to complete their booking.

**Planned changes:**
- Add a submit button to the BookingSection component
- Connect the button to the existing handleSubmit function
- Style the button consistently with the current UI design
- Disable the button during form submission to prevent duplicate requests

**User-visible outcome:** Users can now click a submit button to complete their booking after filling out the form.
