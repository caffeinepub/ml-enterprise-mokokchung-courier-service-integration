# Specification

## Summary
**Goal:** Update the booking form layout and structure to match the uploaded design format.

**Planned changes:**
- Add "General" heading in green at the top of the booking form section
- Add Mode selector toggle with truck (ground) and airplane (air) icons at the top, with truck selected by default
- Restructure form fields into a two-column grid layout: Customer/Consignor Name with Mobile Number, No. of Packages with Approximate Weight(Kg), Origin Pincode with Destination Pincode, Preferred Pickup Date with Email
- Add Verify button next to Mobile Number field
- Update Preferred Pickup Date field to date-time picker with calendar icon, displaying DD-MM-YYYY HH:MM AM/PM format
- Add Address 1 field spanning full width below the grid
- Add optional Address 2 and Address 3 fields in two-column layout below Address 1
- Update all field labels to match design exactly (Customer/Consignor Name, Mobile Number, No. of Packages, Approximate Weight(Kg), Origin Pincode, Destination Pincode, Preferred Pickup Date, Email, Address 1, Address 2, Address 3)
- Remove existing shipping option radio buttons, replacing with Mode toggle
- Add decorative package box illustrations in bottom-right corner of form

**User-visible outcome:** Users see a redesigned booking form with modern two-column layout, mode selector toggle for ground/air shipping, mobile verification button, enhanced date-time picker, additional address fields, and decorative package illustrations matching the uploaded design.
